## What is Secret Republic?

**Secret Republic** is a browser-based role-playing game about cyber security. Players take
missions from the Cardinal, an in-game AI with its own voice. In each mission they ping and scan servers,
connect over SSH-style file services, read intercepted mail, crack protected accounts and run SQL against
live databases. Everything runs in the browser with a minimal, app-like UI that works on phones, tablets
and desktops.

The full game is open source under the MIT license, including the **mission designer**, so you can host
your own world and write your own puzzles.

## Run your own server in two minutes

```bash
git clone https://github.com/nenuadrian/secret-republic-browser-based-cyber-security-rpg-v4.git
cd secret-republic-browser-based-cyber-security-rpg-v4
docker compose up -d --build
# open http://localhost:8080 and create the admin account
```
