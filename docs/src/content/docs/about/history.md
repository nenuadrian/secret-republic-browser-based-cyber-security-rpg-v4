Secret Republic started in **2012** as a browser game about cyber security. Its first
public competition ran until **2016** and gathered more than **13,000 participants**, after which the
world state was reset and the game was rebuilt.

## Versions

| Version | Notes |
| ------- | ----- |
| **V1** | The original game. See the [screenshots](../../game/screenshots/#where-it-started). |
| **V3** | An older, larger codebase with more features, built on a custom framework: [Secret-Republic-Hacking-Browser-Game-V3](https://github.com/nenuadrian/Secret-Republic-Hacking-Browser-Game-V3). |
| **V4** | This project. A rewrite on FuelPHP with a cleaner structure, a mobile-first UI, an AI voice and the in-game mission designer. Modernized in 2026 for PHP 8.5, MySQL 9.7 and Docker. |
